# 老板管账页面状态规则包

> 由导演规则编译。请勿直接编辑。

## 当前策略

- 页面族：`empty-state`
- 状态：pending / page-spec-only
- 已开放能力：当前没有可生成能力

## 可选方案

### 页面内状态

- 规则模板：`state.embedded`
- 适用条件：空数据、错误、无权限或缺少前置条件属于来源页面的状态，不单独替代原页面家族。
- 规则：
- `BL-TPL-004` `embedded-page-state`（页面内状态） 空数据、错误、无权限和缺少前置条件通常是所属页面家族的状态，不能取代原本应有的页面家族。
- `BL-INT-008` `page-state-recovery`（页面状态恢复） Loading、首次空数据、查询无结果、请求错误、无权限和缺少前置条件是不同状态，必须使用不同文案和恢复方式。
