# Boss Ledger 历史模板覆盖回归提示词

## 使用目的

这份清单用于确认新的“导演规则 -> Page Spec -> 固定渲染器”链路已经正确接管原 `templates/template-01` 至 `template-13` 的业务能力。

历史模板已删除，不能作为生成输入。本清单中的业务提示词不指定模板、页面类型、代码或实现方式；系统应自行按当前导演规则选择页面方案。每一次测试都在一个新的 AI 对话中执行。

与 [人工业务回归提示词](manual-regression-prompts.md) 的关系：后者是当前已验收能力的完整业务回归集；本文件从已删除的旧模板出发，补齐历史覆盖视角。两者有重叠是预期的，不需要重复执行同一个场景。

## 判定方式

| 判定 | 含义 |
| --- | --- |
| `应生成` | 需要生成需求说明、页面设计、可浏览预览和快速静态验收结果；人工确认交互和视觉。 |
| `应拦截` | 正确结果是明确说明当前能力缺口，并且不生成伪造的替代页面。它证明能力门禁有效，不是失败。 |
| `随页面验证` | 不是独立页面能力；在相应业务页面的预览中确认。 |

每个提示词均使用同一交付约束：遵循老板管账当前导演规则和已开放能力，自动选择合适页面方案，生成需求说明、页面设计、可浏览预览和快速静态验收结果。若能力不支持，说明能力缺口，不得改变需求含义或临时拼装替代页面。

## 收口标准

可将旧模板迁移视为覆盖完成，需要同时满足：

1. 所有标为“应生成”的用例均生成页面，快速静态验收通过，人工预览符合业务描述。
2. 所有标为“应生成”的用例均完成首次人工验收；未开放能力仍必须报告准确的能力缺口，且不得绕过门禁生成替代页面。
3. 第 2 条用例的固定 Shell 人工检查通过。
4. 第 10 条无结果状态仍保留查询列表本体和恢复操作。

不要求将历史模板的坐标、尺寸、Figma 节点、`C0/C1` 占位符或旧 CSS 规则重新带回工程；这些内容已经被导演规则、主题 Token、Page Spec Schema 和固定渲染器接管。
