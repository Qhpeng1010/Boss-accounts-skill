# Boss Ledger 规则组合回归提示词

这些场景根据导演规则组合页面能力，用于验证规则选择、能力门禁、页面结构和人工交互。它们不属于当前两个快速配方；未明确开放或未通过人工验收的组合必须报告能力缺口，不得自由拼装替代页面。

## 1. 列表 + 统计卡片

```text
创建老板管账的结算单查询列表页。

使用者：财务人员。
主要任务：按结算日期、结算单号、商户名称和结算状态查询结算单，并核对本期汇总。

列表展示结算单号、商户名称、应付金额、实打款金额和结算状态。页面顶部展示本期结算笔数 128 笔、应付总金额 2865400.00 元、实打款总金额 2798600.00 元、打款失败 3 笔。默认每页 20 条。
```

## 2. 列表 + 批量操作

```text
创建老板管账的待审核结算规则查询列表页。

使用者：运营人员。
主要任务：查询待审核规则并批量处理。

支持按规则名称和审核状态查询。列表展示规则编号、规则名称、商户名称、审核状态和创建时间，并支持多选。选中记录后可以批量通过或批量驳回，批量驳回必须二次确认。默认每页 20 条。
```

## 3. 父表 + 可展开子表

```text
创建老板管账的结算批次查询列表页。

使用者：财务人员。
主要任务：查询结算批次并核对批次下的商户明细。

支持按结算批次号和批次状态查询。父表展示批次号、结算周期、商户数量、应付总金额和批次状态。样例批次 B001，结算周期 2026-07-01 至 2026-07-07，商户数量 2，应付总金额 218500.00，状态已完成。展开后展示杭州星云商贸有限公司 120000.00 已打款、上海锦程科技有限公司 98500.00 已打款。父表默认收起子表，默认每页 20 条。
```

## 4. 分组表单

```text
创建老板管账的商户结算信息配置页面。

使用者：财务人员。
主要任务：按信息组配置并核对商户结算信息。

页面包含商户基本信息、收款账户和结算周期三个信息组。商户基本信息包含商户编号、商户名称、所属行业，三项必填；收款账户包含账户类型、账户名称、开户行和银行账户号码，其中账户类型、账户名称、银行账户号码必填；结算周期包含结算周期、结算方式和手续费率，三项必填。页面底部固定显示取消和保存，保存前校验所有必填字段。
```

## 5. 长详情 + 锚点定位

```text
创建老板管账的渠道结算配置详情页。

使用者：财务人员。
主要任务：查看杭州星云商贸有限公司的完整渠道结算配置，不编辑、导出或批量操作。

页面包含基本信息、商户主体、收款账户、结算周期与分账规则、费率配置、审批记录和操作日志七个信息组。信息较多，需要支持快速定位到任一信息组。只读展示商户编号 M10080028707、商户名称杭州星云商贸有限公司、配置状态生效中、收款账户、结算规则、费率配置、审批记录和操作日志。
```

## 6. 分组标签详情 + 指标

```text
创建老板管账的结算账户详情页。

使用者：财务人员。
主要任务：查看结算账户指标和分组信息，不提供编辑。

页面顶部展示账户余额 286540.00 元、可用余额 265400.00 元、冻结金额 21140.00 元三个指标。详情按基本信息、结算配置和资金流水三个标签分组查看。基本信息展示账户名称、商户名称、账户状态和开户时间；结算配置展示结算周期、结算方式和手续费率；资金流水展示流水编号、时间、金额和流水状态。
```
